# Город будущего · живой фон

Живая иллюстрация: нарисованный город, по которому ездит и летает 3D-транспорт —
два автобуса, поезд на эстакаде, робот-доставщик, квадрокоптер и летающие машины с паром.
Вес всей сцены ~2,3 МБ при передаче (видео такого же размера весило бы 5–15 МБ).

## Как открыть

Нужен любой локальный сервер (модули не открываются по `file://`):

```sh
python3 -m http.server 8000
```

и открыть http://localhost:8000.

Полезные параметры адреса:
- `?t=12` — остановить сцену на 12-й секунде (для скриншотов);
- `?debug` — показать траектории и линию горизонта.

## Устройство

- `index.html` — фон, 3D-слой и вырезанные слои поверх него (арка, здание, клумба, фонарь).
- `scene.js` — камера под перспективу рисунка, маршруты в пикселях картинки, анимация.
- `assets/` — фон и слои (WebP), модели (GLB: meshopt-сжатие, квантование, текстуры WebP).
- `vendor/three/` — Three.js 0.180.0 (MIT), минифицированная сборка, без внешних CDN.

Маршруты заданы точками в пикселях исходной картинки 1446 × 1087, поэтому остаются
привязанными к рисунку на любом экране. Небоскрёбы — невидимая «стена глубины»:
летающая машина прячется за ними, а поезд проходит перед ними.

Если в системе включено «уменьшение движения», показывается неподвижный кадр.
